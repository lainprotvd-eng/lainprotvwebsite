    Installation steps

    1. Download the ZIP or RAR archive.

    2. Extract the ZIP or RAR archive.

    3. Move the extracted world folder (named after the map or ending in “save”) into the “saves” folder inside your Minecraft game folder. The world folder should contain “level.dat”.

      Move the file or folder ending in “resourcepack” or “pack” into the “resourcepacks” folder inside your Minecraft game folder.

    4. Open Minecraft, go to Options → Resource Packs, and enable the resource pack you just installed.

    5. Now you can play and enjoy the map :)

    Use the Minecraft version listed for the map and the game folder selected in your launcher.
